# LanDrop 1.8.1 — icon update

Replaces the previous purple branding with the owner's orange/cream speed-folder
design. The orange tile fills the icon canvas; transparent rounded corners replace
the preview's opaque checkerboard and wide border.

Updated assets cover the Windows executable, installer/uninstaller, shortcuts,
tray, native notification image, in-app views, macOS/Linux bundles and existing
Android launcher sources. The tray now embeds a full-canvas 64px asset; the Windows
ICO includes 16/24/32/48/64/256px frames. The Android status notification uses the
matching monochrome symbol. **This release does not contain a new Android APK.**
Android publication remains blocked by the documented exposed signing identity
and incomplete replacement-signing setup. Updated Android source assets do not
constitute a tested or published Android release. See
[Android signing requirements](../../android/signing/README.md).

No discovery, transfer, updater endpoint, signing key, or VPN settings are changed
by this patch. It retains the functional scope and network acceptance-test limits
of [1.8.0](v1.8.0.md).

The Windows build passed 66 Rust tests, 87 frontend tests, strict Clippy and
formatting, and was installed locally with the owner's approval. Executable,
installer and uninstaller icon resources were verified. Desktop release CI
repeats validation and produces signed updater packages. Exhaustive DPI/theme
visual checks and Android device acceptance have not been completed.

Use the existing **Check for updates** action on older desktop versions once
this release is published. The updater endpoint and public key are unchanged.
The 1.8.0 tag and its installers are unchanged; the new artwork is versioned as
1.8.1 rather than replacing an existing release's files.

See [icon production research](../icon-production.md) and the
[reproduction instructions](../../assets/branding/README.md).
