## Coverage limits

This is a delivery, integrity and updater-feed verification. No downloaded package
was installed or launched, no GitHub release was modified, and no VPN/network
settings changed. It does not demonstrate an update-button installation on each
previous version, nor that a separately installed local build is byte-identical
to these public builds. Updater signatures are distinct from Windows Authenticode
and macOS notarization; this check does not certify either.

The existing runtime limitations in [the 1.8.1 release notes](v1.8.1.md) remain:
worldwide two-PC Tailscale transfers, network switching and Mullvad coexistence
are not established by package verification. This desktop release contains no
Android APK and makes no new Android runtime or Tailscale-support claim.
