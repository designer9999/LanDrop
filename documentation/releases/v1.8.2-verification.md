## Build environment and reproduced defects

Windows-native Node 24.18.0, Rust/Cargo 1.98.1 MSVC-hosted toolchain with
`aarch64-linux-android`, Tauri CLI 2.11.4, crate 2.11.5, Android NDK
27.0.12077973, Java 21.0.10, Gradle 8.14.3, AGP 8.11.0, SDK 36.
Local signing/verification uses pinned Build Tools 36.0.0. Release CI uses its
declared Java 17 Linux host; this is not a Windows desktop runtime benchmark.

| Evidence | Finding | Change / verification |
| --- | --- | --- |
| Reproduced | Android Rust compilation failed on `window.unminimize()` | Guarded desktop-only call with `cfg(desktop)`; Android compilation progressed |
| Measured | Initial `.so` had 4 KB LOAD alignment and misaligned RELRO | Android-only 16 KB linker flags; final artifact check pending |
| Code-confirmed | Fresh identity had no permission to write raw shared Downloads | App-owned receive storage plus native MediaStore/SAF export; phone checks pending |
| Code-confirmed | Same-name picked documents could overwrite the send cache | Unique per-file staging directories; native regression test passed |
| Code-confirmed | Millisecond-only history names could collide | UUID-bearing history names; native regression test passed |
| Code-confirmed | Private history lacked matching filesystem/provider access | Narrow app-owned paths added; native export rejects unrelated paths |

The Windows workstation lacks unprivileged symbolic-link creation. No Developer
Mode or machine policy was changed. The local qualification copies the freshly
built native library into the isolated stage's `jniLibs` and runs Gradle with only
the already-completed `rustBuildArm64Release` task excluded. Stale ignored files
from the old generated Kotlin package were removed only in that staging tree.
Kotlin incremental compilation/daemon settings were disabled for the local Gradle
invocation to avoid a C:-registry/D:-project path mismatch. These are local build
workarounds, not altered shipping runtime behavior.

## Known coverage limits

No 16 KB-page device or API 24–28 SAF device test is yet claimed. Android automatic
Tailscale discovery is not implemented. Large-file sending still reads picked
content into JavaScript memory; the bounded streaming fix applies to **export**,
not the whole send pipeline. No application-wide performance improvement,
background-lifetime guarantee, Google Play qualification, or all-device guarantee
is inferred from unit tests or a successful build.
