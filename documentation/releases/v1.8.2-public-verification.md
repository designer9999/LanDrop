## Coverage limits

This task verified delivery, integrity and the public updater feed. The verifier
did not install or launch the downloaded desktop packages, mutate GitHub, alter
VPN settings or access physical devices. Updater signatures do not establish
Windows Authenticode or macOS notarization. These checks do not prove automatic
update-button installation from every historical version, worldwide two-PC
Tailscale transfers, network switching, or Mullvad coexistence. Android automatic
Tailscale discovery is not established by this release verification. Separate
native APK and emulator checks are explicitly owned by the qualification report.
