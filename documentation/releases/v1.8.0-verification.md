## Installed version and coverage distinction

During release builds, the owner supplied a new icon and authorized local
installation. The separate 1.8.1 icon build was built, installed and reopened on
the workstation; [its verification](../icon-production.md) is separate. Therefore
that workstation correctly does not offer the older public 1.8.0 as an upgrade.
Older public desktop installations are eligible for the 1.8.0 feed entry. The
1.8.1 artwork is not silently substituted into the fixed 1.8.0 release.

The original missing-publication cause is resolved. This record verifies delivery,
manifest consistency and updater signatures, not an observed update-button install
on every prior app version. Windows Authenticode/macOS notarization are not
configured. Real two-PC worldwide Tailscale transfers and network-switch/Mullvad
acceptance remain untested, as disclosed in [the release notes](v1.8.0.md).
